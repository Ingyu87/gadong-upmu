# 가동초 업무 길잡이

현재 운영 주소: https://gadong-upmu.vercel.app

2026.9.1. 업무분장표와 학교교육계획서를 기준으로 담당 업무, 학년도별 일정, 참고 공문을 조회하는 정적 웹앱입니다.

## 구성

- index.html: 화면과 기본 스타일
- app.js: 탐색, 계절별 표현, 검색
- basis-ui.js: 업무 기준 표시, 일정, 학년도 선택
- data.json: 현재 웹앱에 반영한 자료
- juri.png 및 아이콘 이미지: 기존 디자인 자산
- vercel.json: 배포 응답 설정

## 로컬 실행

Python이 설치된 환경에서 저장소 폴더에서 실행합니다.

```sh
python -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다.

## 자료 범위

교육력제고 개인 연구활동 제외와 2025·2026학년도 선택 개선을 반영한 운영본입니다. 원본 공문, 다운로드 파일, 수집 기록, 계정 정보는 이 저장소에 포함하지 않습니다. 연결된 자료 전체의 개별 검증이 완료되었다는 의미는 아닙니다.

Vercel의 gadong-upmu 프로젝트에 연결되어 있습니다. main 브랜치에 푸시하면 기존 운영 주소로 자동 배포됩니다.
